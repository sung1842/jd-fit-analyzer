# 교차 검토 (기획자 A, 시각 언어 관점) — 2026-10-25

이번 라운드에서는 추가 fetch를 하지 않았다. 아래 판단은 A, B, C 세 문서에 이미 기록된 근거만 사용한다.

## 1. 동의하는 트렌드와 겹쳐서 강화되는 근거

- **키네틱 타이포 (A-T2 = B-T3)**
  - 동의하는 사례: Signal-A 스크램블, FORMAT, Grande Charte 회전 인사말.
  - 세 문서 모두 "직무명 회전" 아이디어로 수렴했다.
  - 근거가 가장 단단한 트렌드다.
- **실제 콘텐츠·제품을 비주얼로 (A-T6 = B-T6 = C-1, 2, 4)**
  - Infia City, Overworld, Heron, YumLog가 같은 방향을 가리킨다.
  - "추상 일러스트 대신 실제 작업물·리포트"라는 결론은 세 관점이 같다.
  - A의 듀오톤 썸네일 처리(T7)는 C의 실재감 마퀴(섹션 2)에 그대로 붙일 수 있는 표면 처리다.
- **숫자·데이터 조각 (C-4 + B-T7 넘버링/카운터)**
  - A의 대비 타이포(초대형 숫자 + 모노 캡션)와 결합하면 시각적 포인트가 된다.
  - 핏 점수를 타이포 히어로 요소로 쓰는 것을 추천한다.
- **리퀴드/모핑과 오가닉 3D (A-T5 = B-T4)**
  - 두 문서 모두 "CTA나 포인트에만 쓴다"는 같은 결론을 냈다. 동의한다.
- **피해야 할 패턴**
  - 보라-파랑 블롭, 3열 아이콘 카드, 제품 화면 없는 일러스트는 세 문서 모두 지목했다.
  - B가 추가한 "일괄 fade-up"은 시각적 균질함과 같은 문제다.

## 2. 근거가 약하거나 [추정]뿐인 주장

- **A 자체**
  - T3(물성·질감)의 근거는 Half the Sky와 Olivir 두 건뿐이다. Olivir는 브랜딩 X 포스트라 웹 근거로는 약하다.
  - Painted Dog 근거는 [추정]이다.
  - T7(B&W 토글)은 Arc Marumo 한 건이므로 확산도를 "약"으로 내려야 한다.
  - 서체명은 세 문서 모두 확인하지 못했다.
- **B**
  - T2(장난감 인터랙션)를 확산 "강"으로 본 것은 과하다. Brandon Yasin, metic은 [확인]이지만 Tash는 X의 모션 스터디이고, FORMAT 물리는 [추정]이다. "중"이 적정하다.
  - Half the Sky를 "3D·대화형"으로 본 것은 추정이다. CSSDA 태그는 grid, minimal, one page이고, 설명상 석고 부조 질감이 핵심이라 3D와는 거리가 있다.
  - FORMAT Responsive 6.2점은 B만 언급했다. A는 확인하지 못했다.
- **C**
  - Awwwards 쪽 근거 대부분이 [목록] 수준이고, [확인]은 Heron과 Butter 두 건뿐이다.
  - 트렌드 2(HIL 카피 명시)는 사실상 Heron 한 건이 근거다. 업계 트렌드라기보다 **Talentfolio 차별점 제안**으로 분류해야 정확하다. 제안 자체는 강하게 지지한다.
  - "확산 강"으로 표기된 트렌드 7(단일 CTA 반복)은 CSSDA 노미니 중심 근거다. 노미니는 수상작보다 근거력이 낮다.
- **공통 한계**
  - recent.design 항목은 실제 사이트가 아니라 X의 모션 스터디다. 그러니 "웹 트렌드 확산도"의 근거로는 낮게 가중해야 한다.
  - 세 명 모두 영상과 스크린샷을 보지 않았다. 색·질감·모션 질감은 2차 시각 확인이 필요하다.

## 3. 충돌하는 제안과 A의 판단

| 쟁점 | 입장 | A 판단 |
|---|---|---|
| 활기를 어디서 내는가 | C: 배경은 유지하고 콘텐츠 모션에서. B: 드래그 토글로 **배경 팔레트까지** 전환 | **C 쪽**. Skiper39는 유지가 전제다. 팔레트 전환은 배경이 아니라 포인트 색 하나(CTA, 하이라이트, 점수)의 명도·채도 변화로만 처리한다. 배경 색까지 바꾸면 두 역할이 다른 브랜드처럼 보인다. |
| 역할 구분 방식 | B: 팔레트 전환. A: 모티프 구분(콜라주 vs 도트). C: 콘텐츠·데모 전환 | 주 수단은 **C의 콘텐츠 전환**으로 한다. 시각적 보조는 A 방식을 쓰되, 모티프를 히어로 데모 카드 안에서만 다르게 해서 범위를 줄인다. 이렇게 하면 섹션 수가 늘어나도 그래픽이 과밀해지지 않는다. A가 원래 제안한 섹션 단위 모티프 구분은 철회한다. |
| 히어로 비주얼 | A: 타이포 주인공. B·C: 인스펙터 패널/미니 데모 | **둘을 결합한다**. 좌측에 대형 한글 타이포와 회전 직무명, 우측에 데모를 둔다. 데모는 무채색 UI로 두고 포인트 색은 점수에만 써서 시선이 타이포 → 점수로 흐르게 한다. |
| 질감·도트 그래픽 vs 데모 | A: 카드 질감, 도트 매칭 그래픽. C: 제품 UI 중심 | **제품 UI를 우선**한다. 질감은 실재감 마퀴의 포트폴리오 카드(사람의 작업물)에만 미세하게 쓰고, 분석·리포트 UI는 깨끗하게 둔다. 이 대비가 "사람의 작업물 / 에이전트의 분석"을 구분해 준다. 도트 그래픽은 우선순위를 내리고 선택 사항으로 둔다. |
| 리퀴드 CTA의 색 | B: Skiper39와 색 맞춤. 근거 사례 Liquid Button은 핑크·보라 블롭 | 블롭이 핑크·보라로 변하면 피해야 할 패턴과 겹친다. 브랜드 포인트 색 단색으로 모핑한다. |

## 4. 최종 트렌드 Top 6 (세 문서 통합 추천 순위)

1. **히어로 = 만져보는 제품 데모 + 역할 토글** (C-1, C-5, B-T6). 근거가 가장 많고, 단순하다는 평가를 직접 해결한다.
2. **키네틱 한글 타이포** (A-T2, B-T3). 대형 대비 위계, 회전 직무명, 스크램블. 비용은 낮고 효과는 크다.
3. **스크롤 스크러빙 시나리오 워크스루 + HIL 승인 하이라이트** (B-T1, C-3, C-2). 스크러빙은 네이티브 스크롤을 유지하고 Skip 링크를 둔다.
4. **실제 포트폴리오를 비주얼 재료로** (A-T6, A-T7, C-마퀴). 듀오톤으로 처리하고 호버 시 원색을 드러낸다. 카드에는 미세한 질감을 준다.
5. **무채색 + 단일 포인트 컬러, 점수·숫자를 타이포 요소로** (A-T1, C-4, B-T7 카운터). Fit Report 해부 섹션의 시각적 축이다.
6. **절제된 마이크로인터랙션 세트** (B-T4, B-T5, B-T8, A-T8). CTA 리퀴드(단색), clip-path 탭 전환, 카드 팬, 아이콘 루프. 마이크로인터랙션은 이 세트로만 제한한다.

제외·보류: 3D 공간 내비게이션(비용과 모바일 부담), 프리로더, 배경 팔레트 전환. 도트 제너러티브와 물리 인터랙션은 선택 사항으로 둔다.
