## 2. 근거가 약하거나 추정뿐인 주장

- **A T7 (흑백↔컬러 이미지 모드)**: 확인된 근거는 Arc Marumo 하나뿐이고, FORMAT·OFFFForum은 [추정]이다. 확산도 "약~중"은 과대평가로 보며 "약"으로 보는 게 맞다.
- **A T3 (물성·질감)**: Painted Dog는 추정이고 Olivir는 브랜딩 작업물이지 웹사이트가 아니다. 웹 근거는 Half the Sky 하나뿐이다. 확산도 "중"은 근거가 부족하다.
- **A T5 (오가닉 3D)**와 **B T4 (리퀴드 모핑)**: 근거가 모두 recent.design의 X 모션 스터디다(B도 이 점을 자인했다). 실제 랜딩에서 전환에 기여했다는 근거는 없다.
- **A T1 (흑백+단일 포인트)**: 근거가 전부 에이전시·럭셔리 사이트다. SaaS나 채용 쪽 근거가 없어서 Talentfolio에 그대로 옮기기에는 비약이 있다(밝은 회색 배경 유지와도 충돌, 3장 참조).
- **B T6 / A T6의 Infia·Overworld**: 포트폴리오용 3D 사이트라 전환형 랜딩에 대한 근거로는 약하다. 메타포만 차용하는 것이 맞다는 B의 판단에 동의한다.
- **C (자기 지적)**: Awwwards 쪽 SaaS 사례는 Heron과 Butter 두 개뿐이다. recent.design 항목은 컴포넌트 수준이다.

## 3. 충돌하는 제안과 판단

1. **배경 톤**: A는 "무채색 저대비 회색 일색"을 현재의 문제로 보고 흑백 대비 강화를 제안했다. 그러나 사용자 조건은 밝은 회색과 은은한 배경 유지다. → **판단**: 배경은 유지하고 대비는 타이포 크기와 포인트 색 하나로 만든다. 흑백 반전 섹션은 최대 1개(예: Fit Report 해부)로 제한한다.
2. **드래그 토글 (B T2) vs 접근성·전환**: 역할 선택은 핵심 전환 분기점이다. 드래그만 있으면 클릭률이 떨어질 위험이 있다. → **판단**: 기본은 명확한 세그먼트 버튼으로 하고, 드래그는 같은 컨트롤에 덧붙이는 보조 수단으로만 쓴다.
3. **카드 질감 (A T3) vs 제품 UI 목업 (B T6, C T1)**: 종이나 스티커 질감이 핏 리포트 같은 데이터 UI의 신뢰감과 충돌한다. → **판단**: 질감은 지원자 쪽 작업물 카드에만, 헤드헌터 쪽 데이터 UI는 깔끔하게 둔다(역할 구분 장치로 활용).
4. **마퀴**: B는 로고 마퀴 남용을 경계했고, A와 C는 포트폴리오 썸네일 마퀴를 제안했다. → **판단**: 로고가 아니라 실제 작업물 마퀴라서 차별성이 있다. 다만 한 줄만 두고 일시정지할 수 있게 한다.
5. **모션 범위**: 스크러빙, 토글, 스크램블, 리퀴드, 팬, wipe, 도트를 모두 넣으면 A가 경고한 "조금씩 다 섞은 AI스러움"이 된다. → **판단**: 시그니처 모션은 2개(스크롤 루프 시퀀스, 역할 토글 전환)만 두고 나머지는 CTA나 호버 수준으로 낮춘다.

## 4. 최종 트렌드 Top 6 (세 문서 통합, 추천 순)

1. **제품이 곧 히어로**: 실제 포트폴리오 카드와 핏 인스펙터 데모를 쓴다(A T6, B T6, C T1).
2. **AI→헤드헌터 승인 루프를 스크롤 시퀀스로**: 4단계 스크러빙에 점수 카운트업과 Skip을 둔다(B T1, C T2·T3).
3. **히어로 안의 역할 분기 토글**: 세그먼트를 기본으로 하고 콘텐츠·톤이 함께 전환된다(A, B T2, C T5).
4. **한글 디스플레이 타이포와 회전 직무명**: 시각적 주인공 역할을 한다(A T2, B T3).
5. **실재감 있는 숫자·리포트 조각과 실명 신뢰 장치**: 허위 수치는 금지한다(B T7, C T4·T6).
6. **절제된 포인트**: 포인트 색 하나와 CTA 한정 마이크로인터랙션(리퀴드·포인터 팬)을 쓰고, 3열 카드·보라 블롭·일괄 fade-up은 금지한다(A T1·3장, B T4·T8·3장, C 3장).

제외하거나 보류한 것: 3D 공간 내비게이션, 프리로더, 흑백 이미지 모드, 전면적인 질감, 도트 파티클. 도트 파티클은 섹션 하나에 한해 선택 사항으로 둔다.
