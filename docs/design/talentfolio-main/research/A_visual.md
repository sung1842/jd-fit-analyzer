## 2. 트렌드

### T1. 흑백 베이스 + 강한 단일 포인트 컬러 — 확산 강
- 근거: FORMAT, Signal-A, OFFFForum (모두 #000/#fff), Emotion (#9047FF 하나), Forge (블랙 + 마룬 하나)
- Talentfolio 적용: 무채색 바탕에 브랜드 포인트 색 하나만 쓴다. 지원자/헤드헌터 역할 구분은 색조를 바꾸지 말고 같은 포인트 색의 명도·채도 차이로 처리한다.
- 주의: 순수 흑백만 쓰면 "활기"가 사라진다. 포인트 색이 히어로와 CTA에서 한 번은 크게 터져야 한다.

### T2. 타이포그래피를 주인공으로 (타이포 인터랙션) — 확산 강
- 근거: FORMAT·Signal-A·Emotion 모두 Typography 태그, Signal-A의 Hover Scramble
- Talentfolio 적용: 한국어 헤드라인은 크기 대비(초대형 디스플레이 + 작은 모노/캡션)로 리듬을 만든다. 직무명이 회전·스크램블되는 효과를 넣을 수 있다(예: "프론트엔드 / 브랜드 디자이너"). 한글은 Pretendard 계열 가변폰트의 굵기 변화를 활용한다.
- 주의: 한글 스크램블은 글자 폭이 흔들리므로 고정폭 처리가 필요하다. 가독성과 접근성(reduced-motion)을 확보할 것.

### T3. 물성·질감 메타포 (석고, 종이, 콜라주, 그레인) — 확산 중
- 근거: Half the Sky(석고 부조로 UI 전체), Olivir(찢어진 종이·텍스처 로고), Painted Dog(일러스트 마스코트, 추정)
- Talentfolio 적용: 포트폴리오를 "작업물 더미"로 은유한다. 카드에 종이 질감, 미세 그레인, 테이프·스티커 같은 디테일을 넣으면 "AI가 만든 매끈함"을 깨기 좋다.
- 주의: 기존 Skiper39 배경 위에 질감을 겹치면 지저분해진다. 질감은 카드 내부에만 둔다.

### T4. 도트·파티클·제너러티브 그래픽 — 확산 중
- 근거: AI Simulation Dot Visuals, Emotion의 마우스 반응 파티클, Animated Sphere Clusters(제목 기준)
- Talentfolio 적용: "인재 풀 → 매칭" 개념을 점이 모였다 흩어지는 그래픽으로 표현한다(헤드헌터 섹션). 매칭 데이터 시각화와도 맞다.
- 주의: Skiper39 배경과 시각적으로 경쟁한다. 한 섹션에만 국한한다.

### T5. 오가닉 3D·부풀린 형태와 비비드 그라디언트 — 확산 중
- 근거: Bloom, Liquid Button Hover, Forge의 Fake 3D
- Talentfolio 적용: 역할 선택 카드나 아이콘에 작은 3D 오브젝트(부풀린 아이콘)를 둔다. 전면 사용이 아니라 포인트로만 쓴다.
- 주의: 범용 보라-파랑 그라디언트 블롭은 곧바로 AI 느낌이 된다(3장 참조). 브랜드 색으로 제한한다.

### T6. 작업물 = 공간/오브젝트 (포트폴리오를 탐험하게 하기) — 확산 중
- 근거: Infia City(프로젝트가 곧 랜드마크), Arc Marumo(캐러셀, 타임코드), OFFFForum(갤러리)
- Talentfolio 적용: 메인에 실제 포트폴리오 썸네일이 흐르는 마퀴나 그리드를 둔다. 이 플랫폼의 콘텐츠 자체가 비주얼이므로 가짜 일러스트보다 실제 작업물 이미지가 낫다.
- 주의: 더미 썸네일의 품질이 곧 인상이 된다. 실제 공개 동의를 받은 작업물만 쓴다.

### T7. 이미지 처리 모드 (흑백↔컬러 토글, 듀오톤) — 확산 약~중
- 근거: Arc Marumo(B&W 토글), FORMAT·OFFFForum(흑백 팔레트에 이미지만 컬러, 추정)
- Talentfolio 적용: 썸네일을 기본 흑백 또는 듀오톤으로 두고 호버하면 원색이 드러나게 한다. 여러 출처의 작업물 톤을 통일할 수 있다.

### T8. 마이크로 애니메이션 아웃라인 아이콘 — 확산 중
- 근거: Animated UI Icon Set, Signal-A의 커서 교체
- Talentfolio 적용: 기능 카드 아이콘이 상태별로 루프하게 한다(업로드→분석→매칭). 단순 카드를 디테일하게 만드는 저비용 수단이다.

## 3. 한물간 / 피해야 할 패턴 (AI 생성 느낌 포함)
- 보라→파랑 그라디언트 블롭과 글래스모피즘 카드를 기본값처럼 쓰는 것 (Tailwind 템플릿 느낌)
- 균일한 둥근 모서리 + 연한 그림자 + 이모지/라인 아이콘을 얹은 3열 기능 카드
- 중앙 정렬 히어로("~를 더 쉽게") + CTA 두 개 + 아래 로고 띠라는 정형 공식
- 의미 없는 3D 추상 렌더나 AI가 생성한 인물·오피스 스톡 이미지 (채용 플랫폼에서 특히 신뢰를 깎음)
- 무채색 저대비 회색 일색 (현재 상태): 차분하지만 "아무 말도 하지 않는" 느낌
- Inter + 굵기 하나만 쓰는 타이포 위계 부재
- 수상작에서는 한 가지 물성이나 콘셉트를 끝까지 밀어붙인다(Half the Sky의 "채팅까지 조각"). 반대로 여러 트렌드를 조금씩 섞는 것이 가장 AI스럽다.

## 4. Talentfolio 메인 시각 언어 제안 (3줄)
1. **무채색 바탕 + 시그니처 포인트 색 1개.** 큰 대비의 한글 디스플레이 타이포를 주인공으로 하고, 직무명 회전이나 스크램블로 활기를 준다.
2. **실제 포트폴리오 썸네일을 비주얼 재료로 쓴다.** 흑백·듀오톤으로 톤을 통일하고 호버 시 원색이 드러나게 한다. 카드에는 종이·그레인·스티커 같은 물성 디테일로 "사람이 만든" 손맛을 더한다.
3. **Skiper39 배경은 그대로 두고, 그래픽 모티프는 섹션당 하나만.** 지원자 쪽은 작업물 더미/콜라주, 헤드헌터 쪽은 도트가 매칭되는 그래픽으로 역할을 시각적으로 구분한다.
