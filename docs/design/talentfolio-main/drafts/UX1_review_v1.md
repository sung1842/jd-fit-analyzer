# UX1 리뷰 v1: 흐름·가독성·전환 (라운드3 D/E/F)

> 근거: ROUND3_BRIEF(최우선), QA_round3_v1(실렌더 사실), 각 시안 index.html·proposal.md 코드 정독. 브라우저는 쓰지 않았다.
> 판단 기준은 다섯 가지다. 첫 5초 이해, 히어로 텍스트·CTA 가독성, 역할 경로(/studio·/desk), "위치는 정리정돈, 모션은 개성", 희망찬 블루/그린 인상.

## D 맑은 아침 하늘 (Blue)

### 유지할 강점
1. **타이포 위계가 가장 정돈돼 있다.** Hahmlet 900 + Instrument Serif 이탤릭 `em` + Outfit 라벨 + Nanum Pen 주석. 역할 섹션 "어느 쪽으로 걸어가시나요?"는 에디토리얼 톤을 잃지 않으면서 질문형이라 선택을 이끈다.
2. **역할 경로가 명확하다.** 히어로 CTA가 `/studio`(작업물 올리기)와 `/desk`(후보 검토하기)로 바로 갈라지고, 역할 카드에도 같은 목적지가 반복된다. 헤드헌터 카드를 코발트로 반전해서 두 역할이 색으로도 구분된다.
3. **섹션 순서가 서사대로 흐른다.** 역할 → 데모 → 루프 → Statement("AI가 제안하고, 사람이 승인합니다") → 작업물 → 숫자 → CTA. 각 섹션이 1~2단 그리드 안에 있어 요소 위치를 예측할 수 있다.

### 꼭 고칠 것
- **P0 히어로 가독성** (`#crowd` L45, `.hero-copy` L46). QA 기준 치명 문제다. 군중이 `height:62vh`, `z-index:3`로 제목 아래 절반을 덮어 "출발", `.hero-sub`, `.hero-cta`가 읽히지 않는다.
  - 수정 방향: 군중 높이를 `34~38vh`로 줄이고 하단에 붙인다. 카피 블록은 군중 위쪽 영역(top 12~14vh)에 두고, 아래 끝이 군중 상단보다 위에 오게 한다.
  - 그래도 겹치면 `.hero-sub`, `.hero-cta` 뒤에 흰 반투명 판(`background:rgba(255,255,255,.85)`, 블러 8px)을 깐다. 군중 스프라이트 크기도 0.7배 정도로 줄인다.
  - 모바일 `#crowd{height:42vh}`(L158)도 28vh로 줄인다.
- **P0 첫 화면 CTA 보장**. CTA가 스케일 팝 stagger로 늦게 등장하고, 200vh 핀 스크럽이 시작되면 바로 페이드된다. CTA는 로드 후 1초 안에 완전히 보여야 하고, 핀 진행 0~0.35 구간에서는 사라지지 않게 한다.
- **P1 마스크 단어 "출발"(`#maskWord` canvas)**. 텍스트가 canvas라서 스프라이트가 늦게 뜨면 빈 칸이 된다. 하늘색 바탕에 흰 실루엣이라 대비도 낮다.
  - 수정 방향: canvas 뒤에 cobalt 실색 텍스트 폴백을 깔고, 마스크 안 군중은 진한 ink 실루엣으로 바꾼다.
- **P1 희망찬 인상**. 하늘 그라데이션(mist)과 해(sun)가 원색 군중에 묻힌다. 군중 정리 후에도 블루가 약하면 `--mist`를 #DCEBFF로 한 단계 진하게 하고, 군중 하단 지면에 연한 cerulean 띠를 둔다.
- **P2 카피**. "이 시작돼요 ↗" 손글씨 주석은 "모두의 출발"에 붙여 읽어야 해서 첫 5초 안에 문장이 바로 안 들어온다. 서브카피 첫 문장에 "지원자는 작업물로, 헤드헌터는 AI 추천으로"처럼 역할 두 개를 명시하는 편이 낫다.
- **P2 nav**. "시작하기" 하나만 있다. 우측에 작은 "헤드헌터" 링크(`/desk`)를 추가해 E와 맞춘다.

### 다른 시안에서 빌려올 것
- E: 군중이 커서에 반응해 깡충 뛰는 인터랙션(가독성 문제 없이 히어로 상호작용을 늘림), nav의 헤드헌터 버튼.
- F: SKIP INTRO 링크(200vh 핀 이탈용).

## E 새싹이 자라는 (Green)

### 유지할 강점
1. **첫 5초 임팩트와 이해도가 가장 높다.** Bagel Fat One "커리어가 / 쑥쑥 자란다"는 무엇을 하는 곳인지 한 번에 말해 준다. 히어로가 `100svh` 단일 화면이라 CTA가 핀 뒤에 숨지 않는다.
2. **CTA 카피가 행동 중심이다.** "🌱 작업물 심으러 가기"(`/studio`)와 "AI 추천 후보 승인하기 →"(`/desk`)는 역할과 다음 행동을 동사로 말한다. nav에도 헤드헌터와 시작하기가 함께 있다.
3. **희망·성장 인상이 확실하다.** sprout/leaf 초록, 스티커 하드 섀도, 성장곡선이 주제와 맞는다. 브리프의 "희망찬 그린"을 가장 직접적으로 충족한다.

### 꼭 고칠 것
- **P0 미니 데모 제목이 흩어진 채로 보임** (`#demo h2[data-m="split"]`, `.demo{height:340vh}` L95). QA에서 글자가 화면 하단에 흩어진 상태로 관찰됐다.
  - 원인 추정: split 등장 구간(p 0~0.3)을 340vh 섹션 전체 기준으로 계산해서, 제목이 화면에 들어왔는데도 진행도가 0 근처에 머문다.
  - 수정 방향: 진행도를 섹션이 아니라 h2 자체 rect로 계산한다. 또는 sticky 핀이 시작되는 시점(top=0)에 등장이 완료되게 한다. 시작 상태에서도 글자 변위는 ±40px 안으로 제한한다.
- **P0 역할 카드 이후 빈 공간** (`#roles` 뒤 → `.demo` 핀 시작 구간). 카드와 데모 사이 공백이 커서 흐름이 끊긴다.
  - 수정 방향: `.demo` 핀 컨테이너 상단 padding을 줄이고, 핀 시작 직후 첫 패널(JD)을 바로 보이게 한다. 역할 카드 퇴장 clip이 끝날 때 다음 블록이 이미 화면에 있어야 한다.
- **P1 히어로 군중 묻힘** (`#crowd` z2, `.hero-score` L69 left 8% bottom 16%, `.sticker`, `.hero-vine`). 성장곡선·스티커·점수 카드가 군중 위에 겹쳐 사용자 요구인 "군중 배경"이 안 보인다.
  - 수정 방향: 하단 25vh는 군중 전용 띠로 비워 둔다. `.hero-score`는 우측 상단(top 18vh, right 6%)으로 옮기고, 스티커 3개는 제목 주변으로 모은다. 덩굴 `#v1/#v2` 하단 시작점(y 820~870)을 위로 올려 군중과 겹치지 않게 한다.
- **P1 역할 카드 링크 정합성** (`article.role.a`). 지원자 카드의 주 버튼이 `/start`("시작하기")이고 `/studio`가 보조다. 지원자 주 경로는 `/studio`로 바꾸고 `/start`는 텍스트 링크로 낮춘다. 헤드헌터 카드는 이미 `/desk`가 주 버튼이라 그대로 둔다.
- **P2 375px**. `.mega` 최소 64px + `white-space:nowrap`(L54)이면 "쑥쑥 자란다" 6글자가 375px에서 넘칠 위험이 있다. 모바일에서 `clamp(48px,15vw,…)`로 바꾸고 실측한다(overflow-x hidden에 가려 잘리는 것도 실패로 본다).
- **P2 이모지 버튼**. "🌱"는 OS마다 렌더가 달라 버튼 정렬이 흔들린다. 인라인 SVG 새싹으로 바꾼다(로고 SVG 재사용).

### 다른 시안에서 빌려올 것
- D: 섹션 그리드 정돈과 Statement 섹션("AI가 제안하고, 사람이 승인")으로 핵심 메시지를 한 번 더 고정하기.
- F: 블루를 sky 쪽으로 섞는 `--horizon` 그라디언트. 초록 단색의 단조로움을 줄이고 "블루 또는 그린" 요구를 넓게 충족한다.

## F 지평선 너머 (Blue → Green)

### 유지할 강점
1. **콘셉트와 제품 루프가 히어로 안에서 일치한다.** 군중 속 한 사람 발견(점선 링, FOUND) → JD 실 연결 → 핏 92 → 승인 도장. 플랫폼이 하는 일(탐색 → 분석 → 사람 승인)을 그대로 보여 준다.
2. **`--horizon` 그라디언트**(sky → teal → field)는 블루와 그린을 한 토큰으로 묶어서, 승인을 field 초록으로 읽히게 한다. 색 의미 설계가 가장 좋다.
3. **SKIP INTRO, 루프 섹션 가로 핀 트랙, "※ 이름·점수는 모두 예시" 표기**. 긴 인트로의 탈출구가 있고, 정보가 예측 가능한 순서로 놓인다.

### 꼭 고칠 것
- **P0 첫 5초에 CTA가 없음** (`.hero-ctas{opacity:0}` L65, `#hero{height:420vh}` L36). 역할 CTA가 4단계(승인) 스크럽 끝에야 wipe로 나타난다. 처음 온 사용자는 화면을 3~4화면 내려야 /studio·/desk를 만난다.
  - 수정 방향: 로드 시 CTA를 바로 보여 준다(1단계부터 opacity 1). 4단계에서는 강조 펄스만 준다. 히어로 핀은 420vh에서 260~300vh로 줄인다.
- **P0 무채색 인상** (`#crowd` fixed, `height:100vh`, `opacity:.3` L27, spot 시 최대 .8 L388). QA 기준 회색 군중이 화면을 덮어 블루/그린이 거의 안 보인다.
  - 수정 방향: 군중을 `position:fixed` 전체 화면에서 히어로 하단 40vh 띠로 한정한다(이후 섹션 배경에서는 제거하거나 opacity .12 이하). 지평선 밴드(sky → field)를 1단계부터 화면 하단에 깔아 군중이 초록 들판 위를 걷게 한다. "어두워짐" 연출은 dim 대신 주변 군중 채도를 낮추고 선택된 사람만 컬러 후광으로 처리한다.
- **P1 제목-군중 사이 큰 여백, 핀 중 상단 절반 빈 구간** (`.kr-title{top:22vh}` L41, 2~3단계). 타이틀이 흩어진 뒤 상단이 비어 정돈되지 않은 인상이 난다.
  - 수정 방향: 2단계부터 상단에 단계 캡션("01 발견 / 02 매칭 / 03 승인")을 고정해 빈 칸을 채운다. JD 카드·핏 카드를 화면 중앙 1/3 높이에 배치한다.
- **P1 히어로 서브카피**. "작업물을 쌓는 사람과 사람을 찾는 사람이 만나는 곳"은 정확하지만 "AI가 찾고 사람이 승인"이라는 차별점이 손글씨 한 줄에만 있다. 서브카피에 넣는다.
- **P2 모바일** (L147–153). reduced-motion·모바일에서 핀을 풀면 카드·실·도장이 absolute로 겹칠 수 있다. 1단 세로 스택 순서(타이틀 → CTA → 카드 → 도장)를 명시한다.
- **P2 Anton 외곽선 "BEYOND THE HORIZON"**. 장식 레이어가 한글 타이틀 뒤에서 가로로 흐르면 375px에서 판독 소음이 된다. 모바일에서는 숨긴다.

### 다른 시안에서 빌려올 것
- E: 단일 100svh 히어로 + 즉시 보이는 동사형 CTA. F의 발견 시퀀스는 히어로 바로 아래 데모 섹션으로 옮기는 안도 검토할 만하다.
- D: 헤드헌터 카드 컬러 반전으로 역할 대비 주기, 2단 그리드 정돈.

## 순위

1. **E 새싹이 자라는**: 첫 5초 이해도, CTA 즉시 노출, 동사형 역할 카피, 희망찬 초록 인상까지 UX 기준을 가장 많이 충족한다. P0(데모 제목 흩어짐, 빈 공간)은 진행도 계산과 간격 문제라 국소 수정으로 해결된다.
2. **D 맑은 아침 하늘**: 정보 배치와 타이포 위계는 가장 좋다. 다만 히어로 가독성 P0이 치명적이다. 군중 레이어만 정리하면 E와 1위를 다툰다.
3. **F 지평선 너머**: 콘셉트와 색 의미 설계는 가장 좋다. 하지만 420vh 인트로 뒤에 CTA가 숨어 있고, 무채색 군중이 화면을 덮는다. 첫 5초 이해와 희망찬 색이라는 두 핵심 요구를 동시에 놓친다. 수정 범위가 구조 수준이다.

**권장 조합**: E를 베이스로 F의 `--horizon` 블루-그린 토큰과 "한 사람 발견" 연출(데모 섹션으로 이동), D의 그리드 정돈과 Statement 섹션을 가져온다.
