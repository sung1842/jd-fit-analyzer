# 네이밍·로고 제안 (talentfolio 메인)

## 진행 방식
Agent 병렬 협업은 쓰지 않고 한 세션에서 두 역할을 번갈아 맡았다. 순서는 A(브랜드 디렉터) 브리프 → B(디자이너) 시안 → A 리뷰 → B 수정이며, 2라운드 진행했다.

## 레퍼런스 근거 (확인 범위를 그대로 적음)
- https://www.loud.kr/ 메인 페이지를 WebFetch로 가져왔다. 확인된 내용은 "로고·캐릭터·패키지 디자인 의뢰, 의뢰 1건당 시안 30개 이상"이라는 서비스 소개 문구뿐이었다.
- 수상작 이미지와 개별 작품 이름은 가져온 본문에 없었다. 공모전 상세 페이지는 따로 조회하지 않았다. **구체 수상작을 근거로 쓰지 못했다.**
- 그래서 일반 원칙을 대신 적용했다: 짧은 영문 소문자 워드마크, 서체 대비로 의미 나누기, 심볼은 점 하나 수준으로 최소화.

## 브리프 (A)
- 구직자(포트폴리오)와 기업(JD·제안) 양쪽이 이름에 드러나야 한다.
- 텍스트 워드마크를 중심에 둔다. 이미지 배지는 거절된 이력이 있으므로 금지한다.
- 토큰 5색 안에서만 색을 쓴다. 파비콘 16px에서도 읽혀야 한다.

## 시안
| 안 | 이름 | 의미 |
|---|---|---|
| L1 | talentfolio (정제) | talent(고딕)는 구직자, folio(Lora 이탤릭)는 기업이 읽는 포트폴리오. 두 단어 사이 sun 점을 '만남'으로 표시 |
| L2 | Offerfolio | 기업 offer + 구직자 folio. 이름 자체가 '역채용 제안'을 말함. 아래 두 호가 마주 봄 |
| L3 | Fitday | 핏이 맞는 날. 아침 하늘 톤. i의 점을 해로 표현 |

## 디렉터 리뷰 기록
**R1**
- L1: 처음에는 talentfolio 한 덩어리였다. "양쪽"이 보이지 않아 서체 분리를 요청했다.
- L2: 처음에는 양방향 화살표 심볼이 있었다. 배지처럼 보인다는 이유로 빼고, 워드마크 아래 얇은 호로 바꾸게 했다.
- L3: 해 원이 컸다. i의 점 크기로 줄이게 했다.

**R2 (수정본 검수)**
- 세 안 모두 워드마크 중심으로 정리됐고 토큰 색만 쓴다.
- L2의 호는 헤더 28px 높이에서 약해진다. 헤더에서는 장식으로만 보면 된다고 판단해 허용했다.
- 파비콘은 두 글자 모노그램으로 정리했다. 16px에서 이탤릭 f가 흐려질 수 있어 L1은 추가 검증이 필요하다.

## 상표 메모 (간이 확인, 정식 조사 아님)
- talentfolio, Fitday: 비슷한 이름의 해외 서비스나 앱이 있을 수 있다. KIPRIS 조회가 필요하다.
- Offerfolio: 일반어를 조합한 이름이라 식별력 판단이 필요하다. 아직 검색하지 않았다.
- 피한 이름: "Wanted", "Remember", "Rallit" 등 기존 채용 브랜드와 유사한 이름.

## 추천 순위
1. **L2 Offerfolio**: 서비스의 핵심 차별점(기업이 먼저 제안)과 양쪽 주체가 이름에 바로 드러난다.
2. **L1 talentfolio**: 전환 비용이 0이고 서체 대비로 양면성을 보강했다. 다만 '역채용'은 이름에 드러나지 않는다.
3. **L3 Fitday**: 톤에는 가장 잘 맞지만, 채용 플랫폼이라는 정체성이 약하다.

## 미검증
- 브라우저 렌더링 확인은 하지 못했다. 이 세션에서 http://localhost:8090/logo/ 를 열지 않았다.
- MaruBuri는 쓰지 않았다. 워드마크는 Wanted Sans + Lora 이탤릭만 사용했다.
