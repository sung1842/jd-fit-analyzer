## 들어가야 할 기능 (19 문서 기준)
1. **간이 기록 입력** — 회고 붙여넣기 + 종류·기간·역할 → 정리 잡(202, 진행 상태 표시)
2. **기록함** — AI 초안(6칸 캔버스 중 채워진 칸, 문장마다 원문 인용 표시)
3. **카드 편집기** — 직접 편집 + "AI 교정" 버튼만(대필 없음), 교정 시 "AI 교정" 라벨 숨김 불가, 바뀐 구간 표시
4. **기록 시점 배지** — "활동 당시 작성" vs "회고 입력(입력일 기준)", 수정 불가
5. **신뢰 등급** — 본인 주장 → 근거 첨부 → 확인됨
6. **공개/철회** — 카드별 공개, 철회 시 기업 리포트 인용이 "비공개 전환됨"이 된다는 안내
7. **동의 2종** — `self_ai`(본인용 AI 정리), `matching`(기업 매칭), 철회 가능
8. **추천 내역 + 제외** — 어떤 기업 공고에 왜 추천됐는지("근거 카드 3장"), 추천 제외
9. 기존: 프로필, 자기소개서, 공고 3칸(관심·지원·보류)

## 공통 조건
- 깔끔·심플, 구조가 한눈에. 메인처럼 화려하지 않게. **AI 티 금지**(✨, 보라 그라데이션, 글로우, "AI가 분석했어요").
- 원칙을 UI로 드러낼 것: 비공개가 기본, 공개는 사용자가 고른 것만, AI는 정리·교정만.
- 접근성: 키보드 순서, 포커스 링, 대비 4.5:1, 색만으로 상태 구분 금지(텍스트/아이콘 병기), aria-live 로 잡 진행 알림, 터치 타깃 44px(모바일).
- 단일 HTML, Pretendard + 로고만 Lora(S_studio 로고 마크업 그대로), anime.js 4.0.2 CDN(`https://cdn.jsdelivr.net/npm/animejs@4.0.2/+esm`), 모션 150~250ms, reduced-motion 대응.
- 1280px·375px 모두 가로 넘침 없음. 예시 인물은 1~7년차 IT 실무자(타깃) 1명, 데이터는 "예시".
- 파일 상단 주석에 "이 시안의 정보구조 가설" 3줄.
