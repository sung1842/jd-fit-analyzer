# 16. 수집 대상 플랫폼 조사 (2026-10-27)

> 설계(데이터 모델·화면 배치·결정 항목)는 [17](17_multi_source_postings_design.md). 리멤버는 약관 금지행위 24호가 검색엔진 외 자동 수집을 금지 → 17 D3 보류. 원티드는 공식 OpenAPI "채용공고 수집 KEY" 신청 가능 → 17 D2.

> 사람인은 **첫 수집 대상**일 뿐, 이 시스템은 플랫폼 공통이다 (SQL 014: `crawled_postings` + `platform`).

## 플랫폼별 메모

### 자소설닷컴
- 상세 URL: `https://jasoseol.com/recruit/<id>` (sitemap 에 `career/<id>` 쌍도 있음).
- 한 공고 안에 **직무별 여러 채용 단위**가 있다 → `extra_facts.positions[]` 로 두고, 검수 행은 공고 1건 단위로 시작 (직무 분리는 후속).
- 공통 필드 매핑: 마감일 → `deadline_date`, 접수 시작 → `apply_start_text`, 자소서 문항은 **개수만**(`resume_count`) 저장. 문항 원문은 SSR 에 없고 저작권·DB권 위험이 커서 저장하지 않는다 (17 §1, 2026-10-27 정정).

### 리멤버
- 경력 조건이 연차 범위로 나온다 → `career_text` 원문 유지, 범위 파싱은 후속.
- 헤드헌터 공고는 회사명이 가려진 경우가 있다 → 규칙 `no_company` 가 격리 → 검수에서 판단.

### 원티드 / 링크드인
- 둘 다 봇 접근을 막고 있다. 09 의 "막으면 멈춘다" 원칙에 따라 크롤러를 만들지 않는다.
- 필요하면 공식 API 계약/허가가 선행 조건 (사용자 결정 사항).
