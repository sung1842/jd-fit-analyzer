# 기업(헤드헌터) 기능 직접 테스트 가이드

> 작성 2026-11-03. 기업 계정으로 서비스 전체 루프(스카우트 건 → 후보 탐색 → 핏 분석 → 승인 → 제안·응답)를 직접 확인하는 순서.
> JD 입력문은 **크롤링으로 수집한 실제 공고**(fit.job_postings, 테스트 전용)에서 뽑았다. 회사명은 테스트용으로만 쓴다.

## 0. 준비

### 0-1. 서버가 떠 있는지 확인
```bash
docker ps --format "{{.Names}}  {{.Status}}"
```
- `jd-fit-analyzer-orchestrator-api-1`, `-worker-1`, `-mcp-server-1`, `-redis-1` 이 모두 `Up` 이어야 한다.
- talentfolio 화면은 http://localhost:3000 (별도 터미널에서 `cd C:\ClaudeWorkspace\test1-main\talentfolio && npm run dev`).

### 0-2. 기업 계정으로 로그인
- 지금 브라우저는 **구직자 계정**으로 로그인돼 있다. 오른쪽 위 **로그아웃** → http://localhost:3000/login → 기업 문으로 `test1234@talentfolio.com` 로그인.
- 로그인 후 자동으로 http://localhost:3000/desk 로 가면 정상. /studio 로 가면 구직자 계정이다.

### 0-3. LLM 이 필요한 테스트
| 표시 | 뜻 |
|---|---|
| 🟢 | LLM 없음 — 지금 바로 가능 |
| 🔴 | Gemini 호출 필요 — **Gemini 결제/한도 복구 후** 가능 (지금 하면 "일시 오류로 재시도 중" → "분석 실패") |

Gemini 한도가 남았는지 빠르게 보는 법 (429 가 0 이면 정상):
```bash
docker logs --since 10m jd-fit-analyzer-mcp-server-1 2>&1 | grep -c 429
```
